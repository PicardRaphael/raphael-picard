# Bras FPS du Runner

public/models/fps/arms.glb : « fps arms (rigged only) » par para (OpenGameArt, CC0, maillage MakeHuman), retexturé (gants et manches, armtex.mjs) puis posé sur le fusil par IK dans un banc Playwright (pose.js, params.js, run.cjs) et cuit en maillage statique dans le repère de l'arme (build.sh : meshopt + webp).

Les chemins des scripts pointent vers le dossier de travail d'origine : à adapter avant de relancer.
